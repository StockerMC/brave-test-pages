$popup filter test

Setup

  • Brave (this PR): enable brave://flags/#brave-adblock-popup-blocking and relaunch. Add under Custom filters in brave://settings/shields/filters.
  • uBlock Origin (MV2): install it from brave://settings/extensions/v2. In its dashboard, under Filter lists, enable "My filters", then add the same line under "My filters" and apply.
  • Keep Shields up on this page.
  • Variants to run once each: Shields down on this page, and the flag off. Every case should open in both.

URL parameters: target (a URL the filter matches, default https://example.org/), allowed (a URL it doesn't match, default https://example.com/) and redirect (a URL prefix that 302-redirects to the URL-encoded URL appended to it). The default redirect uses httpbin.org, so the redirect cases need it to be reachable. xframe adds a case that frames this page from that URL, which must be a copy of this page on another origin.

Cases

"Blocked" means a window opened and closed right away and the target never loaded. With this PR a blocked popup is also listed under the blocked pop-up icon in the address bar, where you can open it. Cases with a window the page can see record their own result after 2 s. For the rest, look at the tab and click Opened or Blocked.

Click Ready before each case. uBO lets a popup through if its URL is the same as the last link you clicked, in any tab and however long ago, so without this one case can change the next one's result.
