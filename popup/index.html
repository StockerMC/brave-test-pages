$popup filter test

  1. Add as a custom filter (Brave: brave://settings/shields/filters, with brave://flags/#brave-adblock-popup-blocking on. uBO: "My filters").
  2. For each row, click reset, then the button or link. uBO lets through the last link you clicked, so reset keeps one case from affecting the next.
  3. Blocked means a tab or window opens and closes right away. In Brave it's then listed under the blocked pop-up icon in the address bar.

With Shields down or the flag off, everything opens. Rows marked * behave differently in uBO.
